# spec.md — โปรเจค `stock-locator` (ใบจดสต๊อค + ค้นหาโลเคชั่น/ใบจ่ายแยกโลเคชั่น)
> ไฟล์หลัก: `projects/stock-locator/stock.html` · เครื่องมือ: `projects/stock-locator/xlsx_to_stock.py`
> แหล่งข้อมูล: ไฟล์ xlsx `LAY OUT 02 … 23-11-69` (ชีต "ใบจดสต๊อค", "สินค้า", "รวม") — **ไม่เก็บ xlsx ใน repo** (ข้อมูลสต๊อคบริษัท)

## เป้าหมาย
- ใบจดสต๊อค (xlsx): คีย์รหัส → ดึงสินค้า/หน่วย/โลเคชั่น/หมายเหตุอัตโนมัติ + ช่องจำนวน
- `stock.html`: ค้นหาของง่าย ใส่หลายรหัสได้ → ได้ใบจ่ายแยกทีละโลเคชั่น (ติ๊กหยิบแล้ว) ใช้บนมือถือหน้างาน เสิร์ฟผ่าน GitHub Pages

## เสร็จแล้ว
- (24 พ.ย. 2026) ไฟล์ xlsx: เพิ่มชีต "ใบจดสต๊อค" 200 แถว — คีย์รหัส → สินค้า/หน่วย จากชีต "สินค้า", โลเคชั่น/หมายเหตุ จากชีต "รวม" (รหัสอยู่หลายที่ = รวมคั่นด้วย ,) + ช่อง "จำนวน" ให้คีย์เอง (คอลัมน์ C ก่อนหน่วย รับเฉพาะตัวเลข ≥ 0) — เพิ่มชีตด้วยการแก้ XML ตรง เพราะ openpyxl จะลบ shape 105 ชิ้นในชีต "ผังให้เดย์ปรับเองได้"
- (24 พ.ย. 2026) `stock.html` ค้นหาโลเคชั่น + จ่ายหลายรหัสแยกทีละโลเคชั่น ข้อมูลฝังจากใบจดสต๊อค 186 แถว + ชีตสินค้า 2,788 รหัส — test 12/12 ผ่าน (`stock.html?test=1`), ทดสอบ Chromium จอ 390px แล้ว
- `xlsx_to_stock.py` แปลง xlsx → ฝังข้อมูลใน stock.html (แทนเฉพาะช่วง `@@DATA-START/END`)
- (25 พ.ย. 2026) ไฟล์ xlsx: เพิ่ม 7 ชีตแยกตามโลเคชั่น (ลำดับตาม LOC_ORDER) คอลัมน์ ลำดับ/รหัส/สินค้า/จำนวน/หน่วย/หมายเหตุ — สูตรดึงจากชีต "ใบจดสต๊อค" อัตโนมัติ (คอลัมน์ H ซ่อน = เลขแถวต้นทาง, INDEX+MATCH ไล่ต่อจากตัวก่อน ไม่ใช้ FILTER) พื้นที่พิมพ์ยืดตามจำนวนรายการ (OFFSET) — ตรวจแล้ว 192/192 แถวตรงต้นทาง ไม่มีสูตร error
- (27 พ.ย. 2026) แยกเป็นโปรเจคของตัวเองใน `projects/stock-locator/` (ย้ายจาก root — URL เปลี่ยนเป็น `/projects/stock-locator/stock.html`)

## การตัดสินใจสำคัญ (อะไร + เพราะอะไร)
- ฝังข้อมูลในไฟล์ (เดย์เลือก) — อัปเดตสต๊อค = ส่ง xlsx ใหม่ → รัน `python projects/stock-locator/xlsx_to_stock.py ไฟล์.xlsx` → commit / ข้อควรระวัง: ถ้า repo public ข้อมูลสต๊อคเปิดให้ทุกคนเห็น (แจ้งเดย์แล้ว)
- ใส่รหัสอย่างเดียว ไม่ใส่จำนวนจ่าย (เดย์เลือก)
- ลำดับกลุ่มโลเคชั่นตาม `LOC_ORDER` (ผมตั้งเอง: ห้องควบคุม → HRCI ในห้องควบคุม → อุณหภูมิปกติ → HRCI ในอุณหภูมิปกติ → GRAIN → หน้า GRAIN → ด้านนอก) รอเดย์ยืนยันลำดับเดินจริง
- แถวที่ซ้ำกันทั้งแถวในใบจด (10 รหัส) แสดงตามจริง ไม่รวมเอง
